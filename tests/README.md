# Prévia visual

A pasta mantém apenas o laboratório do design system, ainda em validação.

Abra `tests/design_system_preview.tscn` no Godot e execute com **F6**.

- Clique esquerdo: próxima tela.
- Segurar por 0,8 s: tela anterior.
- Propostas: menu, jogo, placar, descarte, reinicialização e guia visual.
- Dados fictícios; nenhuma tela atual ou arquivo de placar é alterado.

Detalhes e licença da fonte em `design_system/README.md`.

As cenas e scripts de testes dos sistemas já incorporados ao jogo foram removidos. A cena `scenes/input_test.tscn` e seu script continuam presentes porque ainda são usados pela introdução como calibração de cliques.
